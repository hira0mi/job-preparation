# ML / Algorithms / Python — учебный репозиторий

Мой личный учебный репозиторий для систематического изучения
Machine Learning, алгоритмов и Python.

Здесь я собираю конспекты, решённые задачи, эксперименты и небольшие
проекты, чтобы отслеживать свой прогресс, закреплять материал и
готовиться к техническим собеседованиям и соревнованиям.

> Репозиторий ведётся в первую очередь для обучения, поэтому здесь
> могут встречаться незавершённые решения, ошибки и неидеальный код.

## 📚 Содержание

### Machine Learning
- `classic_ml/` — классическое машинное обучение
  - Logistic Regression
  - Decision Trees
  - ...
- `cv/` — Computer Vision
- `interview/ml/` — вопросы и задачи для ML-собеседований

### 🐍 Python
- `python/` — особенности Python, конструкции языка и небольшие задачи
- `algorithms/` — алгоритмы и структуры данных

### 🗄️ SQL
- `sql/` — SQL и задачи для практики

### 📝 Notes
- `notes/` — конспекты и дополнительные материалы

## 🎯 Цели

- научиться самостоятельно писать ML-код без постоянной зависимости
  от LLM;
- систематизировать знания по классическому ML и Deep Learning;
- укрепить Python;
- изучить алгоритмы и структуры данных;
- освоить SQL;
- подготовиться к ML/DS техническим собеседованиям;
- участвовать в ML-соревнованиях;
- постепенно собрать полноценное портфолио проектов.
